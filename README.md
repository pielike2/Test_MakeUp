Основные технические моменты реализации:

Основная логика сделана через Руку (Hand) и её связь с объектами HandTarget. При нажатии на HandTarget рука выбирает объект своей следующей целью с помощью метода "Hand.instance.SetTarget(HandTarget)". При достижении цели вызывается метод из HandTarget "HandUse(Hand hand)". Рука работает по Состояниям (enum State).

HandTarget (потенциальный цели для руки) делятся на Инстурмент (Tool) и Лицо (WomanFace). Если цель руки (target) - Инстурмент (Tool), то рука либо переходит в Состояние TakingTool и движется к объекту, чтобы его взять, либо переходит в Состояние ReturningTool, чтобы вернуто на место инструмент в руках, и движется к объекту, чтобы его положить, после чего уже переходит в Состояние TakingTool и движется к Цели, чтобы его взять. Если цель руки (target) - Лицо (WomanFace), то рука либо переходит в состояние TargetFace и движется к объекту, чтобы повзаимодейсвовать с ним инструментов в руках; при достижении лица Рука включает анимацию использования инструмента с помощью метода "RunAnimation(HandAnimation.Type, Action)" и переходит в Состояние "UsingTool", в котором ожидает окончания анимации. Если у руки нет цели, то она переходит в Состояние "Idle", при котором занимает готовности позицию на груди в девушки (между лицом и местом, где ранее стоял инструмент).

Макияж меняется в копоненте "WomanMakeUp" простым скрытием и отображением слоёв PSD изображения. Метод "SetMakeUp" получает тип инструмента "Tool.Type" и номер цвета, который нужно применить, отображает нужный слой из коллекции и сркывает остальные.
